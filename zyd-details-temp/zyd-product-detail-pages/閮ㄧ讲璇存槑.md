# ZYD 二级产品详情页网站包

这个压缩包**不包含首页**，不会覆盖你已经完成的 `index.html`。它只包含可从首页产品卡片跳转进入的产品详情页面。

## 包含的 8 个页面

1. `products/custom-halo-lit-letters/`
2. `products/ultra-slim-led-light-box/`
3. `products/custom-led-neon-sign/`
4. `products/architectural-wayfinding-system/`
5. `products/outdoor-pylon-monument-sign/`
6. `products/metal-acrylic-logo-sign/`
7. `products/custom-landscape-furniture/`
8. `products/complete-signage-system/`

每个页面都包含：

- 深色高端产品首屏
- MOQ、效果图与交期信息
- 产品介绍
- 技术参数表
- 定制选项
- 应用行业
- 生产流程
- FAQ
- WhatsApp 询价表
- 相关推荐
- 手机端自适应

## 合并到现有 GitHub 网站

将压缩包中的以下内容上传到你现有仓库根目录：

```text
product-assets/
products/
integration-snippets/
```

不要删除或覆盖你现有的首页。

## 修改 WhatsApp 号码

打开：

```text
product-assets/js/site-config.js
```

将：

```js
whatsappNumber: "8613800000000"
```

替换成你的真实号码。只填写国家区号和数字，不要填写 `+`、空格或横线。

## 修改首页产品卡跳转

参考：

```text
integration-snippets/homepage-product-links.html
```

例如：

```html
<a href="products/custom-halo-lit-letters/">CONSULT →</a>
```

GitHub Pages 项目仓库部署时，建议使用相对路径，不要使用以 `/` 开头的绝对路径。

## 本地预览

进入网站根目录后运行：

```bash
python -m http.server 8000
```

浏览器访问：

```text
http://localhost:8000/products/custom-halo-lit-letters/
```
