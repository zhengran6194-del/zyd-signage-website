# ZYD 标识独立站部署说明

这是一个无需安装环境、可直接部署到 GitHub Pages 的静态网站包。

## 部署前必须修改

打开 `site-config.js`：

```js
window.ZYD_SITE_CONFIG = {
  whatsappNumber: "8613800000000",
  salesEmail: "sales@example.com",
  companyName: "ZYD Zhiyudao Sign"
};
```

将 `whatsappNumber` 改成你真实的 WhatsApp 号码：

- 必须包含国家区号
- 只保留数字
- 不要填写 `+`、空格或横线

例如英国号码：

```js
whatsappNumber: "447599932002"
```

然后在 `index.html` 中搜索 `sales@example.com`，替换成你的真实业务邮箱。

## 本地预览

可以直接双击 `index.html` 打开。

也可以在网站文件夹内执行：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

## 上传 GitHub Pages

1. 在 GitHub 新建一个仓库。
2. 将压缩包解压后的全部文件上传到仓库根目录。
3. 进入仓库的 `Settings`。
4. 点击左侧 `Pages`。
5. 在 `Build and deployment` 中选择 `Deploy from a branch`。
6. Branch 选择 `main`，文件夹选择 `/ (root)`。
7. 点击保存，等待 GitHub 生成网站地址。

## 当前网站功能

- PC、平板、手机自适应
- 手机端折叠菜单
- 产品分类和行业解决方案
- 工厂实力和生产流程
- 全球案例展示
- FAQ
- 全站 WhatsApp 引流按钮
- 询价表自动整理客户信息并打开 WhatsApp
- SEO 标题、描述、Open Graph 和结构化数据
- 图片全部放在本地，不依赖外部图片网站

## 询价表说明

这是纯静态网站，不会在服务器保存客户信息。

客户填写表单后，网站会自动生成一段完整的 WhatsApp 询盘内容，包括：

- 姓名
- 公司
- 国家
- 产品类型
- 尺寸
- 数量
- 项目要求
- 参考文件名称

浏览器无法自动把客户选择的文件上传到 WhatsApp，因此 WhatsApp 打开后，客户还需要手动发送图片、PDF 或 AI 文件。
